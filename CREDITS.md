# Credits and Acknowledgments

repsp builds upon knowledge and technical foundations created by the PlayStation Portable homebrew, reverse engineering, and preservation communities:

* **Simple DirectMedia Layer (SDL)**: The SDL team and contributors for providing cross-platform windowing, graphics, and audio support under the zlib license.
* **psprecomp**: sp00nznet for pioneering static recompilation tooling and calling convention analysis for the Sony PSP.
* **uOFW**: The uOFW team for reverse-engineering and documenting the PSP firmware kernel and user-mode APIs.
* **PSP Developer Wiki**: Community contributors who documented the hardware, memory layout, and container formats of the PSP.
* **reexec / rexbox / reJSRF / rePIU**: The reexec static recompilation project suite for providing architectural patterns, workflow principles, and coding standards.
