# repsp v0.0.29

A sceCtrl button filter, so an app can change the buttons a game reads.

Issue [#63](https://github.com/reexec/repsp/issues/63):

- `repsp::hle::ctrl::SetButtonFilter()` (default none) receives the buttons a sceCtrl read is about to return, and the game gets the buttons it returns.
- It runs on the guest thread inside the HLE call, so an app may read guest memory to decide.
- Input recording logs the value before the filter.
- `ctrl_probe` checks it.
- Use: an app's autoplay.

Verified: build and CTest pass on Win64 (Visual Studio and Ninja) Debug/Release and Linux x64 Debug/Release.
