# repsp v0.0.5

Input: sceCtrl, a runtime vblank clock, keyboard and gamepad, sceDmac.

Issue [#9](https://github.com/reexec/repsp/issues/9): the runtime `VblankClock` (59.94 Hz, reference-counted start and stop, subscribers, `WaitNext`, stepping for tests) with the display HLE turned into a subscriber; the platform input contract (a keyboard and gamepad snapshot from the SDL UI thread, a default mapping, neutral input when headless); `repsp_hle_ctrl` (`sceCtrlSetSamplingCycle`, `sceCtrlSetSamplingMode`, `sceCtrlReadBufferPositive`, an injectable input source); `repsp_hle_dmac` (`sceDmacMemcpy`); additions to the NID name table; the probes `vblank_probe`, `ctrl_probe` and `dmac_probe`. Commits `cdbbd0f`…`0108595` on task branch `i009-input`, squashed into this release's merge commit.

Verified: Win64 Debug/Release and Linux x64 Debug/Release builds with CTest 14/14. In the consumer reDMP1 the real module went past its input setup to the next library's unimplemented call.
