# repsp v0.0.33

Implements three HLE functions needed on the first-run path after the opening movie (no savedata → language select → profile creation → autosave → title).

Issue [#71](https://github.com/reexec/repsp/issues/71):

- `IoFileMgrForUser` `sceIoCloseAsync` (`0xFF5940B6`): uses the existing asynchronous result model; the `fd` is removed when the result is collected.
- `sceRtc` `sceRtcGetCurrentClockLocalTime` (`0xE7C27D1B`): PSPSDK `ScePspDateTime`.
- `IoFileMgrForUser` `sceIoGetstat` (`0xACE946E8`): PSPSDK `SceIoStat`.
- Checked by `iofile_probe` and `sysmem_probe`. Registered NIDs 168 → 171.
- Consumer: [reexec/reDMP2#9](https://github.com/reexec/reDMP2/issues/9) (reaches the title screen, waiting for input).
- Squashed into this release's merge commit.

Verified: build and CTest 23/23 on Win64 Debug/Release (zero warnings in repsp code). Linux x64 in CI.
