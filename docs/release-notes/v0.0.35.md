# repsp v0.0.35

Fixes broken alpha in DXT5 textures, and adds an optional GE draw and texture trace.

Issue [#75](https://github.com/reexec/repsp/issues/75):

- `texture_decode.cpp` assembled DXT5's 48-bit alpha indices with the low 32 bits (block bytes 8–11) and high 16 bits (12–13) swapped. Fixed, with a 16-texel regression check in `ge_probe`.
- The GL and software paths share this decoder, so both are fixed.
- Diagnostic: `REPSP_GE_TRACE=<directory>` and `REPSP_GE_TRACE_FRAMES=<first>-<last>` (off by default). Each draw writes one state line, and each unique texture its raw bytes and a decoded image (`ARCHITECTURE.md` §2.9).
- Consumer: [reexec/reDMP2#15](https://github.com/reexec/reDMP2/issues/15) (the song list text on the song select screen is restored).
- Squashed into this release's merge commit.

To other consumers: alpha in DXT5 textures changes (to the correct values). Check any workaround tuned to the old DXT5 alpha.

Verified: build and CTest 23/23 on Win64 Debug/Release (zero warnings in repsp code). Linux x64 in CI.
