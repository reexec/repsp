# repsp v0.0.31

Boot-path HLE for a second title; the consumer presents its first frame.

Issue [#67](https://github.com/reexec/repsp/issues/67):

- `tools/nid_hash.py` (NID = first 4 bytes of SHA-1(name)) and 67 more names in `nid_names.cpp` (216 → 283).
- Implemented through the measured loop:
  - `SysMemUserForUser`: `sceKernelSetCompiledSdkVersion`, `SetCompilerVersion`, `MaxFreeMemSize`, `TotalFreeMemSize`
  - `ModuleMgrForUser`: `sceKernelGetModuleId`, `GetModuleIdByAddress`
  - `sceUtility`: `GetSystemParamInt`, `Load/Unload{,Av,Net}Module`
  - `sceImpose`: `SetLanguageMode`, `SetUMDPopup`
  - the `ThreadManForUser` VPL family, with scheduler wait and wake
- A probe for each; registered NIDs 146 → 168.
- Consumer: [reexec/reDMP2#3](https://github.com/reexec/reDMP2/issues/3).

Verified: build and CTest 23/23 on Win64 Debug/Release (zero warnings in repsp code); in the consumer the boot runs to the 600-vblank limit and presents its first frame. Linux x64 in CI.
