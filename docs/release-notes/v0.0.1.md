# repsp v0.0.1

The first release: the skeleton of the runtime shared by PSP title recompilation projects.

Issue [#1](https://github.com/reexec/repsp/issues/1), runtime bootstrap: rules, the layer and CMake skeleton, the SDL3 submodule (`release-3.4.x`, `ee239da`), the platform layer (address space, guarded calls, host threads, paths, SDL3 contracts), the `PARAM.SFO` parser, `GuestMemory` with a 512 MiB window (PSP mirror folding), the NID registry with SHA-1, the lifter-neutral recompiled-code contract (`guest_cpu.h`), five probes, and Win64 and Linux x64 CI. Commits `dd96f43`…`26b8533` on task branch `i001-runtime-bootstrap`, squashed into this release's merge commit.

Verified: build and CTest 5/5 on Win64 Debug/Release (Visual Studio 17 2022, x64) and Linux x64 Debug/Release (WSL Ubuntu 24.04, GCC 13).
