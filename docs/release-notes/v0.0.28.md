# repsp v0.0.28

Gamepad shortcuts the same as reCT3 (rexbox).

Issue [#61](https://github.com/reexec/repsp/issues/61):

- **Menu**: the combo moves from LB+RB+Y to **LT+RT+Y**. A trigger counts once past half way.
- **Quit**: a new combo, **LT+RT+L3+R3 held 1 s**, requests a quit once per hold. The app ends the way closing the window ends it.
- While LT+RT are down, Y, L3 and R3 do not reach game input.
- The logic is a pure state function, `UpdateGamepadShortcuts`, which `platform_probe` checks without SDL.
- The quit combo also works with the software renderer.

Verified: build and CTest pass on Win64 (Visual Studio and Ninja) Debug/Release and Linux x64 Debug/Release.
