# repsp v0.0.36

Adds a filter that can change the whole controller sample (buttons and analog stick).

Issue [#77](https://github.com/reexec/repsp/issues/77):

- `repsp::hle::ctrl::SetSampleFilter(std::function<void(SceCtrlData&)>)`, none by default.
- It is called for each sample `sceCtrlReadBufferPositive` returns to the game, after the button filter (on the guest thread, inside the HLE call).
- Input recording logs pre-filter values. Cleared in `Register()`/`Shutdown()`. `SetButtonFilter` is unchanged.
- `ctrl_probe` Check 9; `ARCHITECTURE.md` §2.10.
- Consumer: [reexec/reDMP2#19](https://github.com/reexec/reDMP2/issues/19) (analog-lane autoplay).
- Squashed into this release's merge commit.

Verified: build and CTest 23/23 on Win64 Debug/Release (zero warnings in repsp code). Linux x64 in CI.
