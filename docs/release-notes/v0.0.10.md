# repsp v0.0.10

The GE colour test.

Issue [#19](https://github.com/reexec/repsp/issues/19): the GE colour test commands (`CTE` 0x27, `CTEST` 0xD8, `CREF` 0xD9, `CMSK` 0xDA) are decoded, and the rasterizer discards fragments by comparing the masked colour with the reference (NEVER, ALWAYS, EQUAL, NOTEQUAL) after texture combination and before the alpha test; a reproducing case added to `ge_probe`; `docs/kb/ge.md` updated. Commits `7da1855`…`68d2c4a` on task branch `i019-play-entry`, squashed into this release's merge commit.

This was the only repsp defect the consumer met between its menus and its gameplay screen.

Verified: Win64 Debug/Release and Linux x64 Debug/Release builds with CTest 19/19.
