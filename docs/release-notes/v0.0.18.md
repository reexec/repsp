# repsp v0.0.18

The default host stack reservation for guest threads goes from 64 MiB to 8 MiB.

Issue [#37](https://github.com/reexec/repsp/issues/37): the 64 MiB default (#32) was a safety net for lifted code whose transfers between functions piled up on the host stack. With such transfers handled by a run loop, host calls nest only as deep as guest calls, so the default is now 8 MiB, the usual Linux main-thread default. The setter (`SetGuestHostStackReserveBytes`) and the stack-overflow stop report stay. `kernel_sched_probe` checks setting another value and restoring it. On Windows it also checks that recursion beyond the default reservation is caught as a `Stack overflow` stop report.

Verified: Win64 (Visual Studio) Debug/Release, and Linux x64 Debug/Release, build and CTest 22/22.
