# repsp v0.0.2

The PRX loader and the stop contract.

Issue [#3](https://github.com/reexec/repsp/issues/3): the parser and relocator for relocatable PRX modules (`e_type` `0xFFA0`; `SHT_PRXRELOC`, `R_MIPS_32/26/HI16/LO16` with offset-base and address-base segments), `ParsePrx` and `RelocateToBuffer` (`repsp_module`) and `LoadPrx` (`repsp_runtime`); `sceModuleInfo` and the import and export tables; the stop contract `RaiseStop`/`repsp_raise_stop` (the innermost `GuardedRun` ends with the reason, and `REPSP_STOP_ON_UNIMPLEMENTED` stops through it); `prx_probe`; kb `prx-format.md`. Commits `2c45e66`…`fdee722` on task branch `i003-prx-loader`, squashed into this release's merge commit.

Verified: Win64 Debug/Release and Linux x64 Debug/Release builds with CTest 6/6. In the consumer reDMP1, the relocation of a real module (3,747,092 bytes, 37,010 relocations) matched byte for byte both the lifter's relocation and a separate reference implementation.
