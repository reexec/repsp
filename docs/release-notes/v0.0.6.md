# repsp v0.0.6

Audio: sceAudio output, the sceSasCore mixer, sceAtrac3plus with silent decoding.

Issue [#11](https://github.com/reexec/repsp/issues/11): the platform audio contract reshaped for a pull model (an SDL3 stream; a dummy device consuming at the same rate when headless); `repsp_hle_audio` (6 sceAudio functions: an eight-channel mixer, output waits paced by consumption); `repsp_hle_sascore` (13 sceSasCore functions: VAG ADPCM, pitch, volume, envelopes; reverb values accepted but not mixed); `repsp_hle_atrac` (11 sceAtrac3plus functions: RIFF container parsing, stream buffers, frame and sample accounting; a replaceable decoder contract with `SilentDecoder`); counted external wait sources in the scheduler and a fix to the preemption check for external host threads; ModuleMgr loading only known firmware PRX files as HLE modules; the probes `audio_probe`, `sas_probe` and `atrac_probe`. Commits `883abab`…`d1846f8` on task branch `i011-audio`, squashed into this release's merge commit.

Known limits: ATRAC3 and ATRAC3plus decode to silence (no permissively licensed decoder exists, so the decoder choice is deferred; statistics show `ATRAC decode: silent`). SAS reverb is not applied.

Verified: Win64 Debug/Release and Linux x64 Debug/Release builds with CTest 17/17. In the consumer reDMP1 the real module went past its audio setup to the next library's unimplemented call.
