# repsp v0.0.34

Implements the two clock functions needed after the title screen, on the path mode select → song select → song play → result screen.

Issue [#73](https://github.com/reexec/repsp/issues/73):

- `ThreadManForUser` `sceKernelGetSystemTime` (`0xDB738F35`): writes the 64-bit µs value from the existing clocks' time source into `SceKernelSysClock`.
- `sceKernelSysClock2USec` (`0xBA6B92E2`): splits it into seconds and remaining µs.
- `kernel_sched_probe` item 19 checks monotonicity, the 2^32 µs split and null pointers. Registered NIDs 171 → 173.
- Consumer: [reexec/reDMP2#13](https://github.com/reexec/reDMP2/issues/13) (a song is played to its result screen; EXIT returns to the title).
- Squashed into this release's merge commit.

Verified: build and CTest 23/23 on Win64 Debug/Release (zero warnings in repsp code). Linux x64 in CI.
