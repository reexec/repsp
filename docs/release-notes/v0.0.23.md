# repsp v0.0.23

A Dear ImGui overlay, a window title with FPS, window shortcuts, and display and GL options.

Issue [#48](https://github.com/reexec/repsp/issues/48) brings over rexbox's platform features.

- **Overlay**:
  - Dear ImGui v1.93.0 (MIT, submodule `third_party/imgui`) builds as the `imgui` static library. Apps register a builder through `include/repsp/platform/overlay.h`.
  - It is created with the OpenGL renderer only.
  - Tab and the gamepad's LB+RB+Y open and close it. While it is open, the game sees no buttons pressed.
  - The UI scale follows the window size, but never drops below 1.0.
- **Window title**: `<app title> - OpenGL <major>.<minor> - FPS : <n.n>` (`Software` for the software renderer). FPS counts actual presents over about one second. The title is changed on the window's thread only.
- **Shortcuts**:
  - Alt+1..6: the window at 1x..6x of 480x272.
  - Alt+Enter and a left double click: toggle borderless fullscreen.
  - Ctrl+1..8: rendering scale.
  - Alt and Ctrl combinations never reach game input.
- **Display options**: window scale, fullscreen, VSync, aspect ratio (keep, stretch, integer) and output filter (nearest, linear).
- **GL options**:
  - Rendering scale.
  - MSAA: off, 2x, 4x or 8x, lowered to what is supported. Render-to-texture reads after a resolve.
  - Texture filtering: as the game sets it, linear, or anisotropic 2x..16x.
- **Stats sources**: presented FPS, process memory, and GPU memory. When the driver does not report GPU memory, the sum of this HLE's resources is shown.
- `gl_probe` checks the MSAA resolve pixels.

Measured (one title, input script to gameplay, three runs):

- Mean present interval 20.12-20.15 ms.
- No unresolved-address dispatches, no crashes.
- It also runs through with MSAA 4x at rendering scale 2x.

Confirmed by the user in windowed mode: menu, options and shortcuts.

Verified: build and CTest pass on Win64 (Visual Studio) Debug/Release and Linux x64 Debug/Release.
