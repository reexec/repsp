## 리뷰 1 (`9e56475` 기준)

확인한 것: Win64 Release 새 빌드와 CTest 11개 통과, 등록한 NID 13+4개의 SHA-1 일치, psprecomp 헤더·타이틀 이름 없음, SDL을 전용 UI 스레드 하나에서만 쓰는 구조. 아래를 고친다.

1. **`SIGNAL` 뒤의 `END`**(`ge_interpreter.cpp` `RunList`): 지금은 `SIGNAL` 다음 `END`가 리스트를 끝낸다. `SIGNAL`과 `FINISH`는 각각 바로 뒤의 `END`와 한 쌍이다. `SIGNAL`+`END`는 리스트를 끝내지 않고 그 다음 명령으로 이어 가며, `FINISH`+`END`만 리스트를 끝낸다. `ge_probe`에 `SIGNAL, END, (그리기), FINISH, END` 리스트로 그리기가 실행되는지 검사를 더한다.
2. **`CALL` 스택**: `RunList`의 지역 변수라 stall 뒤 재개하면 사라진다. `QueueSlot`으로 옮긴다. 넘침과 빈 스택의 `RET`는 조용히 무시하지 말고 정지 보고한다. probe: 호출된 하위 리스트 안에서 stall 후 재개.
3. **명령 예산 소진**: 지금은 끝나지도 stall도 아닌 상태로 조용히 돌아온다. 정지 보고로 바꾼다.
4. **큐 순서**: 앞 리스트가 stall/pause인데 새 리스트를 바로 실행한다. 앞 리스트가 끝날 때까지 `Queued`로 두고 순서대로 실행한다. probe 추가.
5. **sync mode 0**: 리스트가 stall/pause 상태면 0을 바로 돌려주지 말고 설계 §3대로 스케줄러로 대기한다(리스트가 끝날 때 깨움). `sceGeBreak`는 아무 일도 안 하고 0을 돌려주는 stub이다. 범위 밖이므로 등록을 빼서 이름 붙은 정지로 드러나게 한다(`sceGeContinue`도 pause를 실제로 푸는 probe가 없으면 뺀다).
6. **그리지 않는 primitive**: points, lines, line-strip, bezier, spline이 조용히 버려진다. `unsupported` 통계에 종류별로 세어 `FormatStats`에 나오게 한다.
7. **VRAM 경계**(`render_backend.cpp` `Fragment`): 프레임·깊이 버퍼 쓰기 주소가 stride에 따라 VRAM 2 MiB를 벗어나 RAM으로 접힐 수 있다. VRAM 범위를 벗어나는 쓰기는 버리고 센다.
8. **표시와 덤프**(`hle_display.cpp`): vblank마다 같은 프레임을 다시 덤프한다. 덤프와 `frames_presented`는 `SetFrameBuf`로 프레임버퍼가 지정(latch)된 때에만 올리고, vblank 수는 따로 둔다. `topaddr` 0은 검은 화면을 보낸다.
9. **주소 계산**: `OFFSET_ADDR`가 `base`를 덮어쓰고 `ORIGIN_ADDR`의 값은 쓰이지 않는다. 공개 자료(psdevwiki GE 명령 표, PSPSDK `pspgu`)로 `BASE`/`OFFSET_ADDR`/`ORIGIN_ADDR`와 `JUMP`/`CALL`/`VADDR`/`IADDR`의 주소 식을 확인해 맞추고 출처를 KB에 적는다.
10. **`THIRD_PARTY_NOTICES.md`**: psprecomp MIT 고지에 저작권 줄(`Copyright (c) 2026 sp00nznet`)이 빠졌다.
11. **KB**(`docs/kb/ge.md`, `display.md`): 다음을 **미확정/미구현**으로 적는다. 즉시 실행 때문에 signal 핸들러가 리스트 전체가 끝난 뒤에 도는 점(behavior 1의 일시정지 의미와 다름), 480×272 고정 클립(화면 밖 렌더 타깃), 미구현 기능(culling, stencil, color mask, fog, 텍스처 필터·mipmap, skinning·morph), SDL 호출이 UI 스레드 하나에 묶인 구조와 그 한계(macOS). 인터럽트 규칙(전달 시점, 스택, 대기 금지)은 `docs/kb/scheduler.md`에 적는다.
12. (낮음) 해석기 상태가 파일 범위 전역(`g_ds`, `g_xf`, `g_lt` 등)과 클래스 멤버로 나뉘어 있다. `GeInterpreter` 멤버로 모은다.

완료 기준: 위 1~11, 네 구성 빌드와 CTest. 커밋 제목 끝에 `(#7)`.

## Review 1 (at `9e56475`)

Checked: a fresh Win64 Release build with all 11 CTest tests passing, the SHA-1 of every registered NID, no psprecomp header or title name, and SDL confined to one UI thread. To fix:

1. **`END` after `SIGNAL`** (`RunList`): `SIGNAL` and `FINISH` each pair with the `END` that follows; `SIGNAL`+`END` does not end the list, only `FINISH`+`END` does. Add a `ge_probe` case (`SIGNAL, END, draw, FINISH, END`).
2. **`CALL` stack**: it is a local of `RunList` and is lost across a stall; move it into `QueueSlot`, and report overflow and `RET` on an empty stack as stops. Probe: stall inside a called sub-list, then resume.
3. **Command budget**: exhaustion returns silently with the list neither done nor stalled; make it a stop report.
4. **Queue order**: a new list runs at once even while an earlier one is stalled or paused; keep it `Queued` and run lists in order. Add a probe.
5. **Sync mode 0**: on a stalled or paused list, wait through the scheduler as design §3 says instead of returning 0. `sceGeBreak` is a silent stub; unregister it so it surfaces as a named stop (and `sceGeContinue` too unless a probe shows it resuming a paused list).
6. **Undrawn primitives**: points, lines, line strips, bezier and spline are dropped silently; count them per kind and show them in `FormatStats`.
7. **VRAM bounds** (`Fragment`): frame- and depth-buffer writes can leave the 2 MiB of VRAM and fold into RAM; drop and count such writes.
8. **Present and dumps** (`hle_display.cpp`): the same frame is dumped again at every vblank; count `frames_presented` and dump only when `SetFrameBuf` latches a frame buffer, keep the vblank count apart, and present black for `topaddr` 0.
9. **Address arithmetic**: `OFFSET_ADDR` overwrites `base` and `ORIGIN_ADDR`'s value is unused; confirm the formulas of `BASE`/`OFFSET_ADDR`/`ORIGIN_ADDR` and `JUMP`/`CALL`/`VADDR`/`IADDR` from public sources (psdevwiki, PSPSDK `pspgu`), fix them, and cite the sources in the KB.
10. **`THIRD_PARTY_NOTICES.md`**: the psprecomp MIT notice lacks its copyright line (`Copyright (c) 2026 sp00nznet`).
11. **KB**: record as unconfirmed or unimplemented — signal handlers running only after the whole list (immediate execution), the fixed 480x272 clip, missing features (culling, stencil, colour mask, fog, texture filtering and mipmaps, skinning and morphing), and the single SDL UI thread with its limit (macOS); interrupt rules go to `docs/kb/scheduler.md`.
12. (Low) Interpreter state is split between file-scope globals and class members; gather it in `GeInterpreter`.

Done when: items 1-11, the four build configurations and CTest. Commit titles end in `(#7)`.
