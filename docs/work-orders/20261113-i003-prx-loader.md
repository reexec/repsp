## Review 1 (2026-11-13, at `7495865`)

Verification: the relocation was compared across three implementations — repsp `RelocateToBuffer`, reDMP1's patched `allegrexrecomp relocate`, and a reference the reviewer wrote from design §2 alone — and the original module at `0x08804000` matched in all 3,747,092 bytes (37,010 relocations). The PRX loader itself passes. One contract found in the consumer's (reDMP1 #3) review is added on this branch: R1, `repsp::platform::RaiseStop(const char* reason)` with a C `repsp_raise_stop(const char* reason)`, as rexbox's `RunGuarded`/`RaiseStop`. The innermost `GuardedRun` ends the run and returns the reason in `GuardedRunResult` (new fields such as `stopped`, `stop_reason`). The mechanism is platform-safe rather than a C++ exception (Win32 `RaiseException` with a dedicated code caught by `__except`; Linux the per-thread guard stack with `siglongjmp`), with the constraint that no C++ frame with destructors sits between the stopping C frame and the guarded call written in the comments and `ARCHITECTURE.md`, and the choice and its grounds in the work log. The NID registry's `REPSP_STOP_ON_UNIMPLEMENTED` stops through it too, and `platform_probe` gains checks for the stop reason and for a stop inside nested guarded calls.

Done when: R1 is in, the Win64 Debug/Release and Linux x64 builds and CTest pass, and the work log has a "Review 1" section.
