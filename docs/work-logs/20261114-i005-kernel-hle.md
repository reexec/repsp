# 작업 로그: 커널 런타임 및 커널·UMD HLE (`i005-kernel-hle`)

## 1. 작업 요약

[설계 문서](../design/20261114-i005-kernel-hle.md)와 [작업 지시서](../work-orders/20261114-i005-kernel-hle.md)에 따라 `repsp_runtime`, `repsp_recomp`, `repsp_hle_kernel`에 다음 기능을 구현하고 검증했다.

1. **커널 객체 테이블, 단조 시계, VFS (`0fe3855`)**
   - `KernelObjectTable`: 생성·조회·삭제 및 핸들 수명 관리
   - `Clock`: 단조 마이크로초 시계 및 타이머 기준
   - `Vfs`: `disc0:`/`umd0:`(읽기 전용), `ms0:`(읽기/쓰기) 마운트 및 호스트 경로 매핑, 디렉터리 순회, 파일 디스크립터 관리
2. **사용자 파티션 및 배턴 스케줄러 (`f755707`, `2d266ad`)**
   - `UserPartition`: PSP 사용자 메모리(`0x08800000`–`0x0A000000`) 256바이트 정렬 블록 할당/해제
   - `Scheduler`: 단일 코어 배턴 패싱(`HostThread` + `std::condition_variable`), 우선순위·FIFO 대기열, `Yield`/`Sleep`/`Delay`/`Wait` 및 `Poll()` 퀀텀 선점, 워커 스레드 내부 `GuardedRun` 정지 전파
   - `sceKernelStartThread` 인자 전달: 게스트 스택에 인자 버퍼를 16바이트 정렬 복사한 뒤 `$a0 = arglen`, `$a1 = guest_argp` 설정 (출처: uOFW `threadman.c` `sceKernelStartThread` 규약)
   - `MakeReadyLocked`: 휴면(`kDormant`) 스레드가 `StartThread`를 통해 준비 상태로 전이할 수 있도록 보정
3. **오류 코드, `KernelConfig` 계약, `REPSP_HLE_TRACE` (`3f9405b`)**
   - `kernel_errors.h`: 공개 출처가 확인된 PSP 커널 오류 코드 정의 (미확인 오류 코드는 추측하지 않고 `SCE_KERNEL_ERROR_ERROR = 0x80020001` 폴백 사용)
   - `kernel.h`: `KernelMount`, `KernelConfig`, `Register(const KernelConfig&)`, `PrintKernelSummary()`
   - `NidRegistry`: `REPSP_HLE_TRACE`, `REPSP_HLE_TRACE_LIMIT`, 호출 횟수 집계 및 요약 출력
4. **커널·UMD HLE 65종 구현 (`1af1d43`, `2d266ad`)**
   - `SysMemUserForUser`, `ThreadManForUser`, `IoFileMgrForUser`, `ModuleMgrForUser`, `LoadExecForUser`, `UtilsForUser`, `StdioForUser`, `Kernel_Library`, `scePower`, `sceSuspendForUser`, `sceUmdUser` 대상 총 65개 NID 구현 및 등록
   - MIPS o32 64비트 인자 정렬(`sceIoLseek`/`sceIoLseekAsync`: `$a0` fd, `$a1` 패딩, `$a2:$a3` 64비트 offset, `$t0` whence, `$v0:$v1` 반환) 반영
5. **테스트 프로브 및 문서화 (`4791d3e`, `eddcb06`)**
   - `nid_probe`: 65종 커널·UMD NID 전수 등록 검증 추가
   - `kernel_sched_probe`, `sysmem_probe`, `iofile_probe` 추가 및 CTest 등록
   - `docs/kb/scheduler.md`, `docs/kb/kernel-errors.md`, `docs/kb/vfs-io.md`, `docs/kb/README.md`, `ARCHITECTURE.md` 갱신

# Work Log: Kernel Runtime and Kernel/UMD HLE (`i005-kernel-hle`)

## 1. Work Summary

Implemented and verified the kernel runtime and 65 kernel/UMD HLE functions in `repsp_runtime`, `repsp_recomp`, and `repsp_hle_kernel` according to [the design document](../design/20261114-i005-kernel-hle.md) and [the work order](../work-orders/20261114-i005-kernel-hle.md).

1. **KernelObjectTable, Monotonic Clock, and Vfs (`0fe3855`)**: Object handle management, monotonic microsecond clock, and `disc0:`/`umd0:` (read-only) + `ms0:` (read-write) VFS mounts.
2. **UserPartition and Baton Scheduler (`f755707`, `2d266ad`)**: 256-byte aligned user-partition block allocator (`0x08800000`–`0x0A000000`), single-core baton scheduler (`HostThread` + `std::condition_variable`), `Poll()` quantum preemption, worker-thread `GuardedRun` stop propagation, and `StartThread` argument stack copy (`$a0 = arglen`, `$a1 = guest_argp`, per uOFW `threadman.c`).
3. **Kernel Errors, `KernelConfig`, and `REPSP_HLE_TRACE` (`3f9405b`)**: Documented PSP kernel error constants with `SCE_KERNEL_ERROR_ERROR = 0x80020001` fallback, `KernelConfig`/`Register`/`PrintKernelSummary` contract, and `NidRegistry` call tracing/summary.
4. **65 Kernel & UMD HLE Functions (`1af1d43`, `2d266ad`)**: Implemented and registered all 65 NIDs across 11 libraries, including MIPS o32 64-bit argument alignment for `sceIoLseek`/`sceIoLseekAsync`.
5. **Probes & Documentation (`4791d3e`, `eddcb06`)**: Added `kernel_sched_probe`, `sysmem_probe`, `iofile_probe`, extended `nid_probe` with all 65 NIDs, and updated `docs/kb/` and `ARCHITECTURE.md`.
