# 작업 로그: UMD 교체 모델과 링크 디스크 경로 HLE (issue #79, #80)

설계 문서: [20261124-i079-umd-swap.md](../design/20261124-i079-umd-swap.md)

## 1. 구현 요약

### #79 UMD 교체 모델 (`74e32ec`)
* **`include/repsp/hle/umd.h`**: 호스트/UI 스레드와 게스트 스레드에서 안전하게 호출할 수 있는 UMD 교체 API 추가:
  * `IsReplacePermitted()`, `GetDriveStat()`, `EjectDisc()`, `InsertDisc(const std::filesystem::path& disc_root)`, `SetReadyDelayMs(uint32_t)`, `GetReadyDelayMs()`.
  * 드라이브 상태 비트는 PSPSDK `pspumd.h`(`0x01 NOT_PRESENT`, `0x02 PRESENT`, `0x04 CHANGED`, `0x08 INITING`, `0x10 INITED`, `0x20 READY`, 기본 준비 상태 `0x32`).
* **`src/hle/kernel/umd.cpp`**:
  * `sceUmdCheckMedium`(`1` 디스크 있음 / `0` 없음, PSPSDK `pspumd.h` 기준), `sceUmdReplacePermit`, `sceUmdReplaceProhibit` 구현 및 등록.
  * 교체 허용 플래그 초기값은 금지(`false`). 비허용 시 `EjectDisc()`/`InsertDisc()`는 사유와 함께 거부.
  * `EjectDisc()`는 `disc0:`/`umd0:` VFS 마운트를 해제하고 `0x01`로 전이, `InsertDisc()`는 새 폴더로 재마운트 후 `PRESENT|CHANGED`(`0x06`)를 거쳐 설정 지연(기본 500 ms, 실기 시간 출처 없음) 후 `0x32`로 전이하며 `sceUmdWaitDriveStat*` 대기자를 깨움.
* **`src/hle/kernel/iofilemgr.cpp`**:
  * 꺼낸 동안 `disc0:`/`umd0:` 열기와 이미 열려 있던 `disc0:`/`umd0:` 핸들 읽기·탐색이 `SCE_ERROR_ERRNO_ENODEV`(`0x80010013`)로 실패하도록 세대 카운터(`generation`)와 존재 여부 검사 추가.
* **`tools/umd_probe/main.cpp`**: 상태 전이, 허용/비허용 거부, 꺼낸 동안 `disc0:` 실패, 새 폴더 읽기, `WaitDriveStat` 깨우기 및 `WaitDriveStatWithTimer` 타임아웃 검증.

### #80 링크 디스크 경로 HLE (`062a3b6`)
* **`src/hle/utility/hle_utility.cpp`**: `sceUtilitySavedata` 확장 모드 6종 구현:
  * `12 FILES` (`param+0x5F8` `PspUtilitySavedataFileListInfo`, 80바이트 엔트리), `13 MAKEDATASECURE`, `15 READDATASECURE`, `17 WRITEDATASECURE`, `19 ERASESECURE`, `22 GETSIZE` (`param+0x5FC` `PspUtilitySavedataSizeInfo`).
  * `*SECURE` 파일은 암호화 없이 평문 파일로 저장(실기 세이브 호환 비목표).
* **`src/hle/kernel/iofilemgr.cpp`**: `IoFileMgrForUser::sceIoDevctl` 등록 및 `ms0:` 여유 공간 조회(`0x02425818`) 구현. 호스트 `std::filesystem::space` 결과를 32 KiB 클러스터(`sector_size=512`, `sector_count=64`)로 변환하되 32비트 부호 있는 바이트 곱셈 오버플로를 막기 위해 최대 `32768` 클러스터(1 GiB)로 클램프. 미지원 명령은 `RaiseStop`.
* **`src/hle/kernel/power_suspend.cpp`**: `sceSuspendForUser::sceKernelVolatileMemTryLock`/`Unlock` 구현(`0x08400000`, 4 MiB, 이중 잠금 시 `SCE_POWER_ERROR_TAKEN_SLOT` `0x802B0200`).
* **`tools/iofile_probe/main.cpp`**, **`tools/utility_probe/main.cpp`**, **`ARCHITECTURE.md`**: 6종 세이브 모드, `sceIoDevctl`, 휘발성 메모리 잠금 probe 추가 및 문서 갱신.

# Work Log: UMD Swap Model and Link-Disc Path HLE (issues #79, #80)

Design document: [20261124-i079-umd-swap.md](../design/20261124-i079-umd-swap.md)

## 1. Summary of Changes

### #79 UMD Swap Model (`74e32ec`)
* **`include/repsp/hle/umd.h`**: Added thread-safe host API (`IsReplacePermitted`, `GetDriveStat`, `EjectDisc`, `InsertDisc`, `SetReadyDelayMs`, `GetReadyDelayMs`) with PSPSDK `pspumd.h` status bits (`0x01..0x20`, default ready `0x32`).
* **`src/hle/kernel/umd.cpp`**: Implemented `sceUmdCheckMedium` (`1`/`0`), `sceUmdReplacePermit`, `sceUmdReplaceProhibit` (starts prohibited), VFS unmount/remount of `disc0:`/`umd0:`, `PRESENT|CHANGED` (`0x06`) → configurable delay (default 500 ms) → `READY` (`0x32`) transition, and `sceUmdWaitDriveStat*` wake-ups.
* **`src/hle/kernel/iofilemgr.cpp`**: Failed `disc0:`/`umd0:` opens and stale-handle reads/seeks with `SCE_ERROR_ERRNO_ENODEV` (`0x80010013`) while ejected or after a disc change.
* **`tools/umd_probe/main.cpp`**: Verified transitions, permit/prohibit gating, ejected `disc0:` failure, remounted reads, waiter wake-up, and timeout.

### #80 Link-Disc Path HLE (`062a3b6`)
* **`src/hle/utility/hle_utility.cpp`**: Implemented extended savedata modes `12 (FILES)`, `13 (MAKEDATASECURE)`, `15 (READDATASECURE)`, `17 (WRITEDATASECURE)`, `19 (ERASESECURE)`, and `22 (GETSIZE)` using plain unencrypted host files.
* **`src/hle/kernel/iofilemgr.cpp`**: Implemented `IoFileMgrForUser::sceIoDevctl` command `0x02425818` (`ms0:` free space, clamped to 1 GiB / 32,768 clusters of 32 KiB to avoid signed 32-bit byte-product overflow); unimplemented commands stop via `RaiseStop`.
* **`src/hle/kernel/power_suspend.cpp`**: Implemented `sceSuspendForUser::sceKernelVolatileMemTryLock`/`Unlock` (`0x08400000`, 4 MiB; double-lock returns `SCE_POWER_ERROR_TAKEN_SLOT` `0x802B0200`).
* **`tools/iofile_probe/main.cpp`**, **`tools/utility_probe/main.cpp`**, **`ARCHITECTURE.md`**: Added probes for all new HLE paths and documented the host API and plain-file secure savedata policy.
