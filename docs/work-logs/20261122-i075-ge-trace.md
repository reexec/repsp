## 2. 소비자 측정 및 원인 규명 (**확인됨**, 소비자: [reexec/reDMP2#15](https://github.com/reexec/reDMP2/issues/15))

  * `prim=triangle-strip cnt=4 vtype=0x00019F(thr=0,uv=3,col=7) uv=[0.00..256.00, 16.00..32.00 / 0.00..16.00 / 96.00..112.00 / 176.00..192.00 / 192.00..208.00] xy=[304..488, 67..243]` (선택 행은 `xy=[274..518, 122..142]`)

* **원인 판정 (설계 §3 표 2행 — `repsp` 디코드 결함)**:

  * 원시 `.bin`을 올바른 리틀 엔디언 48비트 순서(`Read32(blk + 8u) | (Read16(blk + 12u) << 32)`)로 디코드하자 곡 목록 텍스트와 투명 배경이 완전히 선명하게 복원됨을 확인했습니다.

## 2. Consumer Measurement and Root Cause (**confirmed**, Consumer: [reexec/reDMP2#15](https://github.com/reexec/reDMP2/issues/15))

* Captured `REPSP_GE_TRACE_FRAMES=1400-1401` on the consumer's song select screen (`--max-vblanks 3600`, all outputs outside the repo; `124` draw lines, `35` texture files).
* Summary of the draws landing in the right-hand song list area (`xy=[274..518, 67..243]`, addresses omitted):
  * `prim=triangle-strip cnt=4 vtype=0x00019F(thr=0,uv=3,col=7) uv=[0.00..256.00, 16.00..32.00 / 0.00..16.00 / 96.00..112.00 / 176.00..192.00 / 192.00..208.00] xy=[304..488, 67..243]` (selected row `xy=[274..518, 122..142]`)
  * `tme=1 fmt=10(DXT5) w=256 h=256 bw=256 swz=0 lvls=1 flt=5/1 wrap=0/0 tfunc=0(a=1,dbl=0) uv_so=(1.000,1.000,0.000,0.000)`
  * `abe=1(op=0,s=2,d=3,sf=0x000000,df=0x000000) ate=1(f=6,r=0,m=0xFF)`
* **Classification (design §3 row 2 — `repsp` decode defect)**:
  * The decoded `_dec.bmp` itself showed the exact pixel noise and opaque grey background blocks seen on screen.
  * In [src/gpu/texture_decode.cpp](../../src/gpu/texture_decode.cpp) `DxtTexel()`, the DXT5 48-bit alpha index table was assembled as `Read16(blk + 12u) | (Read32(blk + 8u) << 16)`, swapping the low 32 bits (`blk+8..11`) and high 16 bits (`blk+12..13`).
  * Decoding the dumped raw `.bin` with the proper little-endian 48-bit order (`Read32(blk + 8u) | (Read16(blk + 12u) << 32)`) produced crisp song-list text with clean transparent backgrounds.

## 3. Fix and Verification (`8aeb70a`, **confirmed**)

* **Fix**: Corrected the DXT5 48-bit alpha index assembly in [src/gpu/texture_decode.cpp](../../src/gpu/texture_decode.cpp) to `static_cast<uint64_t>(Read32(blk + 8u)) | (static_cast<uint64_t>(Read16(blk + 12u)) << 32)`.
* **Regression probe**: Added a 4×4 DXT5 test in [tools/ge_probe/main.cpp](../../tools/ge_probe/main.cpp) assigning distinct 3-bit alpha indices (`i & 7`) across all 16 texels and verifying every decoded alpha via `TexelFetch`.
* **Consumer headless frame-dump regression check** (`--max-vblanks 9000`, `2,963` frames, exit `0`, `0` dispatches, dumps not committed):
  * Song select (`frame_1200.bmp`, `frame_1250.bmp`): song-list text is completely sharp and transparent backgrounds are clean.
  * Title (`frame_1000.bmp`), mode select (`frame_1080.bmp`), song play (`frame_1700.bmp`), and failure result (`frame_2000.bmp`): no regressions.
  * Windowed GL check is left to the user per work order §4 (the GL backend shares `texture_decode.cpp`).
* **`repsp` standalone build and CTest**:
  * **Win64 Debug**: **0 project-source warnings**, **23/23 CTest passed** (`6.01 s`).
  * **Win64 Release**: **0 project-source warnings**, **23/23 CTest passed** (`4.21 s`).
