## 1. 수행 내용

* **GE Color Test 구현 (`include/repsp/gpu/render_backend.h`, `src/gpu/ge_interpreter.cpp`, `src/gpu/render_backend.cpp`)**:
  * **증상**: 소비자의 플레이 화면 진입 실행에서 HUD 외곽과 점수 카운터 배경에 마젠타(`#FF00FF`) 컬러키 영역이 투명으로 빠지지 않고 그대로 그려졌습니다.
  * **원인**: GE 통계의 미해독 명령어 목록에 `0x27` (`CTE`, Color Test Enable), `0xD8` (`CTEST`, Color Test Function = `3` `NOTEQUAL`), `0xD9` (`CREF`, Color Reference = `0xC000C0`), `0xDA` (`CMSK`, Color Test Mask = `0xC0C0C0`)가 `8,805`회 기록되고 있었습니다.
  * **수정**:
    * ```mermaid
      flowchart LR
          CMD["GE 0x27 CTE / 0xD8 CTEST / 0xD9 CREF / 0xDA CMSK"] --> DS["DrawState::ctest, ctest_func, ctest_ref, ctest_mask"]
          DS --> FRAG["Fragment: TexCombine 이후 ColorPass(st, c)"]
          FRAG -->|불합격| DROP["프래그먼트 폐기 (return)"]
          FRAG -->|합격| NEXT["AlphaPass -> Depth -> Blend"]
      ```
    * [PSPSDK `pspgu.h` / `guInternal.h`](https://github.com/pspdev/pspsdk) 사양을 확인해 `DrawState`에 `ctest`/`ctest_func`/`ctest_ref`/`ctest_mask`를 추가하고, `GeInterpreter`에서 `0x27`/`0xD8`/`0xD9`/`0xDA`를 해독하며 `Fragment()`에서 텍스처 결합 직후·알파 테스트 직전에 `ColorPass()`(`0=NEVER`, `1=ALWAYS`, `2=EQUAL`, `3=NOTEQUAL`)를 평가하도록 구현했습니다.
* **합성 테스트 추가 (`tools/ge_probe/main.cpp`)**:
  * Test 12("Color test (`CTE`/`CTEST`/`CREF`/`CMSK`): `NOTEQUAL` discards masked color-key pixels")를 추가해 `CTE=1`, `CTEST=3`, `CREF=0xC000C0`, `CMSK=0xC0C0C0` 설정 시 `0xFFFF00FF` 사각형이 폐기되어 배경 `0xFF112233`가 유지되고 비마젠타 사각형 `0xFF00AA00`는 정상 기록됨을 검증했습니다.
* **문서 갱신**:
  * [docs/kb/ge.md](../kb/ge.md) 및 [ARCHITECTURE.md](../../ARCHITECTURE.md)에 Color Test 동작과 출처를 한국어·영어로 반영했습니다.

## 1. Work Performed

* **GE Color Test (`include/repsp/gpu/render_backend.h`, `src/gpu/ge_interpreter.cpp`, `src/gpu/render_backend.cpp`)**:
  * **Symptom**: During the consumer's gameplay entry run, `#FF00FF` magenta color-key areas around the HUD and digit counters were drawn solidly instead of keyed out.
  * **Cause**: Undecoded GE command stats recorded `8,805` occurrences each of `0x27` (`CTE`), `0xD8` (`CTEST=3` `NOTEQUAL`), `0xD9` (`CREF=0xC000C0`), and `0xDA` (`CMSK=0xC0C0C0`).
  * **Fix**: Confirmed register semantics from [PSPSDK `pspgu.h` / `guInternal.h`](https://github.com/pspdev/pspsdk), added `ctest`/`ctest_func`/`ctest_ref`/`ctest_mask` to `DrawState`, decoded `0x27`/`0xD8`/`0xD9`/`0xDA` in `GeInterpreter`, and evaluated `ColorPass()` (`0=NEVER`, `1=ALWAYS`, `2=EQUAL`, `3=NOTEQUAL`) in `Fragment()` after `TexCombine` and before `AlphaPass`.
* **Synthetic probe (`tools/ge_probe/main.cpp`)**:
  * Added Test 12 verifying `CTE=1`, `CTEST=3`, `CREF=0xC000C0`, `CMSK=0xC0C0C0` discards `0xFFFF00FF` (leaving `0xFF112233` untouched) while drawing `0xFF00AA00`.
* **Documentation**:
  * Updated [docs/kb/ge.md](../kb/ge.md) and [ARCHITECTURE.md](../../ARCHITECTURE.md) in Korean and English.
