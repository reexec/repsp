# Work Log: issue #9 — `sceCtrl`, `VblankClock`, Input Contract, `sceDmac` (`i009-input`)

## 1. Work Performed

* **Shared `VblankClock` and `sceDisplay` Subscriber Conversion (`5024c60`)**: Added `include/repsp/runtime/vblank_clock.h` and `src/runtime/vblank_clock.cpp` providing reference-counted 59.94 Hz timer management, ordered subscriber callbacks, `WaitNext(allow_callbacks)`, and deterministic `StepForTest()`. Refactored `src/hle/display/hle_display.cpp` from a private VBlank thread to a `VblankClock` subscriber.
* **Platform Input Contract and SDL3 UI Thread Snapshot (`4ac8696`)**: Added PSPSDK `PspCtrlButtons` constants to `include/repsp/platform/input.h` and updated `UiThreadMain` in `src/platform/sdl/sdl_platform.cpp` to poll keyboard and first-gamepad state (`SDL_EVENT_GAMEPAD_ADDED`/`REMOVED`) through a single mapping table under a mutex snapshot. `SdlInputBackend::Poll` copies the snapshot thread-safely from any thread and returns neutral state when `headless` or `dummy` is active.
* **`sceCtrl` / `sceDmac` HLE, Error Codes, and NID Names (`d13d789`)**:
  * Implemented `repsp::hle_ctrl` (`sceCtrlSetSamplingCycle` `0x6A2774F3`, `sceCtrlSetSamplingMode` `0x1F4011E6`, `sceCtrlReadBufferPositive` `0x1F803938`, 64-entry ring buffer, `SetInputSource`, `GetStats`/`FormatStats`).
  * Implemented `repsp::hle_dmac` (`sceDmacMemcpy` `0x617F3FE6` with bounds checks and `memmove` overlap safety).
  * Added uOFW error codes (`0x80000103`, `0x80000104`, `0x80000107`, `0x800001FE`) to `kernel_errors.h` and 50 SHA-1-verified NID names (`sceDmacMemcpy` and additional `sceAudio`/`sceSasCore`/`sceAtrac3plus`/`sceMpeg` symbols) to `nid_names.cpp`.
* **Probes (`0f78809`)**: Added `vblank_probe`, `ctrl_probe`, and `dmac_probe`, and extended section 7 of `platform_probe` to verify neutral dummy polling, exercising every newly registered NID and runtime contract.
* **Documentation**: Added `docs/kb/ctrl-and-input.md` and updated `docs/kb/display.md`, `docs/kb/kernel-errors.md`, `docs/kb/README.md`, and `ARCHITECTURE.md`.
