* **원인 확정 및 `SwTri` 수정 (`src/gpu/render_backend.cpp`)**:
  * 타이틀 화면의 1픽셀 `#FF00FF` 마젠타 경계선(예: `(157, 184)`)을 추적한 결과, `kPrimTriangles`로 제출된 축 정렬 사각형(예: `[157, 321] x [33, 184]`, UV `[348, 512] x [0, 151]`)을 `SwTri`가 픽셀 중심이 아닌 정수 꼭짓점 + 단순 `Edge >= 0` 판정으로 래스터화하여 아래쪽/오른쪽 배타 경계까지 포함해 아틀라스 패딩(`0xFFFF00FF`)을 표본 추출하는 것이 원인이었습니다.
  * ```mermaid
    flowchart LR
        V["입력 정점 v0, v1, v2"] --> W{"area < 0 ?"}
        W -- 예 --> SW["v1 <-> v2 스왑 (CCW-down-Y 정규화)"]
        W -- 아니오 --> E["픽셀 중심 (x + 0.5, y + 0.5) 평가"]

        E --> TL["IsTopLeftEdge: dy == 0 && dx > 0 또는 dy > 0"]
        TL --> R["e > 0 또는 (e == 0 && top_left) 만 래스터화"]

  * Test 10("Triangle top-left fill rule: axis-aligned 2-triangle quad excludes bottom/right edges")을 추가해 2-삼각형 사각형 `[10, 20) x [10, 20)`의 내부`(10, 10)`~`(19, 19)`만 기록되고 배타 경계 `x = 20` 및 `y = 20`에는 1픽셀도 넘치지 않음을 검증했습니다(`kVertAddr + 0x100u` 사용).
* **문서 갱신**:
  * [docs/kb/ge.md](../kb/ge.md), [ARCHITECTURE.md](../../ARCHITECTURE.md)에 `kPrimTriangles` 픽셀 중심 + top-left fill rule 동작을 한국어·영어로 반영했습니다.

# Work Log: issue #17 — GE Triangle Pixel-Center and Top-Left Fill Rule (`i017-menu-entry`)

* Date: 2026-11-14
* Branch: `i017-menu-entry`
* Related design: [20261114-i017-menu-entry.md](../design/20261114-i017-menu-entry.md)
* Related work order: [20261114-i017-menu-entry.md](../work-orders/20261114-i017-menu-entry.md)

## 1. Work Performed

* **Root-cause confirmation and `SwTri` fix (`src/gpu/render_backend.cpp`)**:
  * Tracing the 1px `#FF00FF` magenta border lines on the title screen (e.g., `(157, 184)`) confirmed that `SwTri` evaluated integer-aligned `kPrimTriangles` quads (e.g., `[157, 321] x [33, 184]` with UV `[348, 512] x [0, 151]`) without pixel-center sampling or a top-left fill rule, causing exclusive bottom/right boundary pixels to sample adjacent `#FF00FF` atlas padding (`0xFFFF00FF`).
  * Updated `SwTri` to normalize negative-area winding (`area < 0` swaps `v1`/`v2`), sample pixel centers `(x + 0.5, y + 0.5)`, and apply `IsTopLeftEdge` (`dy == 0 && dx > 0` or `dy > 0`).
* **Synthetic test (`tools/ge_probe/main.cpp`)**:
  * Added Test 10 ("Triangle top-left fill rule: axis-aligned 2-triangle quad excludes bottom/right edges") using `kVertAddr + 0x100u`, verifying `[10, 20) x [10, 20)` fills interior pixels only and leaves `x = 20` and `y = 20` untouched.
* **Documentation**:
  * Updated [docs/kb/ge.md](../kb/ge.md) and [ARCHITECTURE.md](../../ARCHITECTURE.md) in Korean and English.
