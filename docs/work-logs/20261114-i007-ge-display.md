# Work Log: issue #7 — GE, Display HLE, and Interrupt Delivery (`i007-ge-display`)

* **FPR Callback Contract (`821ca33`)**: Added `get_fpr`/`set_fpr` to `repsp_guest_cpu_ops`, `GetFpr`/`SetFpr`/`Return(float)` to `recomp_helpers.h`, and extended `recomp_contract_probe`.
