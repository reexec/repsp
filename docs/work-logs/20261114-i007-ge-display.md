## 4. 리뷰 1 반영

* **`GeInterpreter` 수정 (리뷰 1~4, 6, 9, 12)**:
  * `SIGNAL`과 `FINISH` 각각 바로 뒤의 `END`와 짝을 맞춰 `SIGNAL`+`END`가 리스트를 끝내지 않게 수정했습니다.
  * `CALL` 스택을 `QueueSlot`으로 옮기고, 넘침 및 빈 스택 `RET`와 명령 예산 소진을 `platform::RaiseStop`으로 보고하게 했습니다.
  * `order_` 큐를 두어 앞 리스트가 stall/pause 상태일 때 새 리스트를 `kGeListQueued`로 대기시키고 순서대로 실행합니다.
  * 그리지 않는 primitive(`points`, `lines`, `line-strip`, `bezier`, `spline`)를 종류별 `unsupported` 통계로 집계해 `FormatStats`에 출력합니다.
  * `OFFSET_ADDR`(`arg << 8`)과 `ORIGIN_ADDR`(`list - 4`)를 `q->offset`으로 분리하고 `JUMP`/`CALL`/`VADDR`/`IADDR` 주소를 `(base | arg) + offset`으로 통일했습니다.
  * 파일 범위 전역(`g_ds`, `g_lt`, `g_xf` 등)을 `GeInterpreter` 멤버로 모았습니다.
* **VRAM 경계 검사 (리뷰 7)**: `render_backend.cpp`의 `Fragment`에서 2 MiB VRAM 범위를 벗어나는 프레임·깊이 버퍼 쓰기를 버리고 `GetOutOfBoundsVramWriteCount()`로 셉니다.
* **`sceGe_user` HLE (리뷰 5)**: `sceGeListSync(..., 0)`/`sceGeDrawSync(0)`가 대기 상태 리스트에서 스케줄러(`WaitCurrent`/`WakeAllWaiters`)로 대기하게 하고, stub이던 `sceGeBreak`/`sceGeContinue` 등록을 제거했습니다.
* **`sceDisplay` HLE (리뷰 8)**: `SetFrameBuf`로 새 프레임버퍼가 latch된 때에만 `frames_presented`와 프레임 덤프를 올리며, `topaddr == 0`이면 검은 화면을 보냅니다.
* **프로브 및 문서 (리뷰 1~11)**: `ge_probe`와 `display_probe`에 리뷰 검증 케이스를 추가하고, `THIRD_PARTY_NOTICES.md`에 `Copyright (c) 2026 sp00nznet`를 추가했으며, `docs/kb/ge.md`, `docs/kb/display.md`, `docs/kb/scheduler.md`를 갱신했습니다.
